## 게임 소개

QWER Climb은 실내 볼더링(bouldering)을 모티브로 한 2D 웹 게임입니다.

캐릭터의 **왼손(Q), 오른손(W), 왼발(E), 오른발(R)**을 하나씩 선택하고, **방향키**로 잡을 홀드를 고른 뒤, **Space**로 잡으면서 벽 꼭대기까지 올라가세요!

간단하지만 중독성 있는 조작, 우스꽝스럽게 늘어나는 캐릭터, 그리고 긴장도 시스템이 합쳐진 **병맛이지만 전략적인** 클라이밍 게임입니다.

## 실행 방법

### 사전 준비

- [Node.js](https://nodejs.org/) 18 이상
- npm (Node.js와 함께 설치됨)

### 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/youreni633/YoureniClimb.git
cd YoureniClimb

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하면 게임이 시작됩니다.

### 빌드

```bash
# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

`dist/` 폴더에 빌드된 정적 파일이 생성됩니다. 아무 웹 서버에서 호스팅 가능합니다.

## 조작법

| 키 | 동작 |
|---|---|
| **Q** | 왼손 선택 |
| **W** | 오른손 선택 |
| **E** | 왼발 선택 |
| **R** | 오른발 선택 |
| **방향키 (↑↓←→)** | 선택된 팔다리 기준으로 해당 방향의 홀드 후보 선택 |
| **Space** | 현재 선택된 후보 홀드를 잡기 |
| **T** | 스테이지 재시작 |
| **ESC** | 메뉴로 돌아가기 |

### 플레이 방법

1. **Q/W/E/R** 중 하나를 눌러 움직일 팔다리를 선택합니다.
2. **방향키**를 눌러 해당 방향에 있는 홀드를 후보로 선택합니다 (하이라이트 표시).
3. 같은 방향키를 다시 누르면 다른 후보로 변경됩니다.
4. **Space**를 눌러 선택된 홀드를 잡습니다!
5. 이 과정을 반복해서 **꼭대기 GOAL 라인**까지 올라가면 클리어!

## 게임 규칙

### 긴장도 시스템

- 화면 오른쪽의 **긴장도 게이지**가 핵심입니다.
- 팔다리가 너무 **멀리 벌어지면** 긴장도가 빠르게 올라갑니다.
- **홀드를 적게 잡고 있으면** (1~2개) 불안정해서 긴장도가 증가합니다.
- **4개 모두 잡고 있으면** 안정적이어서 긴장도가 천천히 회복됩니다.
- 긴장도가 **60%** 이상이면 캐릭터가 떨리기 시작합니다.
- 긴장도가 **85%** 이상이면 화면이 흔들리고 빨갛게 변합니다.
- 긴장도가 **100%**에 도달하면 **추락**합니다!

### 홀드 종류

| 색상 | 이름 | 설명 |
|---|---|---|
| 🟢 초록 | 쉬운 홀드 | 도달 거리가 넉넉하고 긴장도 증가가 적음 |
| 🔵 파랑 | 일반 홀드 | 표준적인 홀드 |
| 🔴 빨강 | 어려운 홀드 | 도달 가능 거리가 짧고 긴장도 증가가 높음 |
| 🟡 노랑 | 미끄러운 홀드 | 잡고 있으면 긴장도가 빠르게 증가! |
| 🟣 보라 | 보너스 홀드 | 잡으면 추가 점수 획득 |

### 점수 & 등급

클리어 시 다음 기준으로 점수가 계산됩니다:

- **클리어 시간** - 빨리 올라갈수록 높은 점수
- **이동 횟수** - 적은 이동으로 올라갈수록 높은 점수
- **추락 여부** - 추락 없이 클리어하면 보너스
- **보너스 홀드** - 보라 홀드를 잡으면 추가 점수

| 등급 | 조건 |
|---|---|
| **S** | 900점 이상 |
| **A** | 700점 이상 |
| **B** | 500점 이상 |
| **C** | 300점 이상 |
| **F** | 300점 미만 또는 추락 |

## 게임 모드

### 튜토리얼

- Q/W/E/R 조작법을 순서대로 안내합니다.
- 간단한 벽에서 기본 조작을 연습할 수 있습니다.
- 화면 하단에 안내 문구가 표시됩니다.

### 자유 모드

- 랜덤으로 생성된 볼더링 벽을 올라갑니다.
- 3가지 난이도 중 선택 가능:
  - **쉬움**: 홀드가 많고 간격이 좁음, 초록 홀드 비율 높음
  - **보통**: 균형 잡힌 난이도
  - **어려움**: 홀드가 적고 간격이 넓음, 빨강/노랑 홀드 비율 높음
